호스텔 용도변경 타당성 분석기 -- 판정 기준 문서 v0.6
========================================================

[주소 검색]
--------------------------------------------------------
* 성공: 도로명 주소 + 지번 주소를 함께 표시
* 실패: 오류 메시지 + "주소를 다시 입력해주세요" 안내
* 기술: Forward geocoding(좌표 확보) → Reverse geocoding(PARCEL, 법정동코드 확보)
* 주의: Forward의 level4LC는 행정동코드일 수 있으므로 반드시 Reverse로 재확인


[1. 용도지역]
--------------------------------------------------------
데이터: 건축물대장 API getBrJijiguInfo

적합: 중심상업/일반상업/근린상업/유통상업지역
  근거: 국토계획법 시행령 제71조, 관광진흥법 제16조

조건부: 준주거(사업계획승인), 일반주거 1~3종(사업계획승인+추가기준),
  준공업(사업계획승인), 자연녹지(사업계획승인, 제한적)
  근거: 관광진흥법 시행령 제13~14조
  * API가 "일반주거지역"으로만 반환하면 종 구분 안내 표시

부적합: 전용주거지역
  근거: 국토계획법 시행령 별표4~6

부적합(문화지구): 문화지구 내 숙박업 불허 (인사동 예외)
  근거: 문화예술진흥법 제8조의3, 서울시 문화지구 조례


[2. 학교환경위생정화구역]
--------------------------------------------------------
데이터: Vworld 장소검색 (Haversine 직선거리)

적합: 200m 초과 또는 학교 없음
  근거: 학교보건법 제6조

조건부: 50~200m (상대정화구역, 심의 필요)
  근거: 학교보건법 제6조, 관광진흥법 개정안

부적합: 50m 이내 (절대정화구역)
  근거: 학교보건법 제6조 제1항


[3. 건축물대장]
--------------------------------------------------------
데이터: 건축HUB API (3단계 fallback)
  1순위: getBrBasisOulnInfo (기본개요)
  2순위: getBrRecapTitleInfo (총괄표제부)
  3순위: getBrTitleInfo (표제부)

적합: 주용도/연면적 등 정보 확인 완료
조건부: API 값이 비어있는 경우 (정부24에서 직접 확인 안내)

용도변경 절차:
  건축물대장 기재변경: 영업시설군(숙박/판매/위락) → 같은 시설군 내
  용도변경 허가: 근린생활/주거업무시설군 → 상위 시설군 변경
  확인 필요: 기타

스프링클러 자동 판정 (연면적 기준):
  300m2 미만: 불요
  300~600m2: 간이스프링클러 (수백~1천만원)
  600m2 이상: 정식 스프링클러 (수천만원)
  근거: 소방시설법 시행령 별표4


[4. 소방/주차/현장 확인]
--------------------------------------------------------
데이터: 수동 체크 (현장 임장 필요)

소방시설 (6항목):
  간이스프링클러, 자동화재탐지, 비상방송/경보, 소화기, 유도등, 비상조명등

피난/방화 (3항목):
  복도 폭 1.8m, 피난계단(3층+), 방화구획

현장 확인-임장 (4항목):
  인접대지 이격거리 1.5m (창문 면) + 불가시 메모칸
  건물 출입구 폭, 주변 소음/유흥시설, 급수/배수 상태

부설주차장: 서울 기준 134m2당 1대
  면제: 사용승인 후 5년 + 1,000m2 미만 (주차장법 시행령 제6조)


[종합 판정]
--------------------------------------------------------
적합: 용도지역 적합 + 학교 적합
조건부: 위 중 하나라도 조건부 또는 조회 실패
부적합: 용도지역 부적합 또는 학교 절대정화구역 또는 문화지구
